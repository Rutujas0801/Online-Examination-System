HOW TO RUN
Just double-click index.html (no Node or install needed).

EDIT
- Name, roles, social links, sidebar menu: js/main.js (top of file)
- Page text: the .html files
- Your photo: replace img/my-profile-img.jpg (keep the same file name)
- Project images: img/portfolio/

CHANGING TAILWIND CLASSES (optional, needs Node)
  npx tailwindcss@3 -c tailwind.config.js -i css/input.css -o css/tailwind.css --minify
